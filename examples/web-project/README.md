# Sample docs workspace

This fixture stands in for a web app. The product wizard catalogs only what this page describes.

## Import

An empty workspace asks you to import a document. The control lives at `/import`.

- You are signed in, and a workspace is selected, before import will run.
- Formats are Markdown, HTML, and DOCX.
- Markdown headings become the outline.
- HTML tags are converted to blocks.
- Word comments are dropped.
- The file stays in the current workspace.
